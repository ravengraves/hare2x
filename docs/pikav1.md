  Quick Reference - What's In

  Types:      int uint i8-i64 u8-u64 f32 f64 bool size uintptr void
              [N]T [_]T []T *[*]T *T nullable *T
              struct union (T|U) enum

  Decls:      fn export type def let const static let

  Control:    if else for switch case match yield(match only) return break continue

  Operators:  + - * / % (arithmetic)
              & | ^ ~ << >> (bitwise)
              == != < > <= >= (comparison)
              && || ^^ ! (logical)
              : (cast) is (type test)
              & * . [] [..] (pointer/array)

  Builtins:   len() size() assert() abort()

  Literals:   42 0xFF 0b10 0o77 3.14 1e-5 true false null void
              "str" 'c' [1,2,3] [0...] T{f=v}

  Modules:    use rt, access rt_ functions.: rt::memcpy, rt::memmove, rt::read, rt::write, rt::abort,  rt::assert, rt::strcmp  - read and write are stubs for non-unix platforms.
              use strings, strings::toutf8, strings::fromutf8_unsafe
